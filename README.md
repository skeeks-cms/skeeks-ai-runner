# skeeks-ai-runner

Исполнитель SkeekS AI на Node.js: адаптеры движков (Codex SDK, Claude Agent SDK) с общим договором шага (`src/engine.mjs`).

**Состояние:** внутренний пилот, не выпущен. Ключи и адреса серверов задаются переменными окружения и файлами на сервере исполнения, в репозитории их нет.

План и решения — [platform-plan, crm/ai-technical.md](https://github.com/skeeks-cms/platform-plan/blob/main/crm/ai-technical.md).
